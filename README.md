# Smart Fridge Recommendation App

This project is a Flask-based web application designed to help users reduce food waste by tracking ingredients and recommending recipes based on expiry dates and available ingredients.

## Features
- User registration and login
- Add fridge ingredients
- Track expiration dates
- Recommend recipes using a weighted algorithm
- View cooking instructions

## Technologies
- Python
- Flask
- SQLite
- HTML, CSS, Jinja2

## Run locally
```bash
pip install -r requirements.txt
python app.py
